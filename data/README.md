# 出生地ガチャ｜2025年計算データ

- `birthplace_probabilities_2025.xlsx`：Excel計算用。都道府県別出生数、確率、累積確率、JavaScript用出力。**「原表照合_2025」シートに公式数値と比較式を追加済み。**
- `birth_prefecture_2025.csv`：計算済み数値をゲーム側へ渡すためのデータ。
- 分母は47都道府県の出生数 **671,255人**。全国確定出生数 **671,270人**との差15人は住所地が外国。
- 数値の出典：厚生労働省 人口動態統計（確定数）2025年 上巻4-3。現在のゲーム内47都道府県データを転記したため、**2026年10月28日、厚生労働省2025年人口動態統計（確定数）第4表と47都道府県すべて原表照合済み。差異0**。
- 統計対象は国内の日本人出生。外国籍住民の出生を含める場合は別途統計を拡充する。
- **ゲーム本体 v0.4 反映済み：** `index.html` の `PREFS` にこのExcel/CSVの「抽選確率」「累積確率」を数値で転記。JavaScript側では確率合計・累積確率を再計算しない。統計データ変更時はExcelで再計算してゲームへ反映する。

公式表：https://www.e-stat.go.jp/stat-search/files?cycle=7&layout=datalist&month=0&page=1&tclass1=000001053058&tclass2=000001053061&tclass3=000001053064&toukei=00450011&tstat=000001028897&year=20250

## 出生数の多い順へ変更（v0.5）

- 元の「都道府県_確率計算」と「原表照合_2025」は並べ替えずに保持。
- Excelに「抽選用_確率順」シートを追加し、出生数の降順で47件の確率・累積確率を計算。
- CSVと `index.html` の `PREFS` を同じ順番に変更。
- `PREFS` の第2列はExcel算出の確率、第3列は並べ替え後の累積確率。JavaScriptは抽選時に再計算しない。
- 元データの数値を変更した場合、抽選用シートを再ソートしてゲームへ反映する。

## 市区町村抽選を実装（v0.6）

- `index.html`：都道府県→該当県の市区町村の2段階抽選。出生地の都道府県と市区町村を表示し、環境欄にも反映。
- `data/municipalities_2025.js`：ゲーム用静的データ。47県別の市区町村配列で、各県内の出生数が多い順。各行は `[市区町村コード, 市区町村名, 県内抽選確率, 県内累積確率]`。確率はExcel計算済みで実行時に再計算しない。
- `data/birth_municipality_2025.csv`：2025年市区町村別の計算済みCSV。47県、正の出生数を持つ1,884市区町村・区。
- `data/municipality_probabilities_2025.xlsx`：市区町村別出生数の公式原表、県別照合、県内確率順の抽選データ、出典。
- 原表には出生数0の自治体が8件あるが、2025年出生数に基づく抽選対象には含めない。原表1,892行、抽選候補1,884行。
- 市区町村の出生数を県ごとに合計すると、既存の47都道府県の確定出生数とすべて一致（国内合計671,255人）。
- デバッグは1,000・10,000・100,000回の二段階抽選。画面では47県の結果と選択県の市区町村内訳を表示し、全47県＋1,884自治体の理論値・実測値・件数をTSVで一括コピー可能。
- `index.html` は同リポジトリの `data/municipalities_2025.js` を読み込む。GitHub Pagesでは自動で同じパスから配信される。

## 父母年齢の同時抽選（v0.12.1）

- `parent_age_joint_2025_smoothed_counts.csv`：父母0～100歳の平滑化済み同時分布モデル（101×101、単位は推計出生件数）。確率の足切り・母親60歳上限を反映済み。対象として残るのは母10～60歳・父10～87歳。実測値と推定・平滑化値が混在する**試作モデル**であり、全セルが公式実測値ではない。
- `parent_age_joint_probabilities_2025.js`：上記モデルで残った2,566組の相対的な重みを**そのまま正規化**した累積確率。母の各歳を全国全出生数へ再重み付けしない。ゲーム実行時は父母セットを1回抽選する。
- 元のモデルは婚内出生で父年齢が判明している652,935件と、母親17歳以下の婚外出生900件を組み合わせた試作（計653,835件）であり、**全国全出生の観測された同時分布ではない**。653,835は確率を正規化する際のモデルの重み合計にすぎず、ゲームの抽選回数でもない。14歳以下の37件は10～14歳へ、婚内出生の55歳以上15件は55～60歳へ、それぞれモデル上で推定配分済み。
- 婚姻判定は引き続き母親年齢別実績に基づく別抽選。17歳以下はゲーム固有ルールとして未婚固定。55歳以上は一括区分の婚内15件／全出生18件に従い55～60歳で一律15/18とする。75歳以上の父について独自の婚姻確率は設定しない（婚外出生の父親年齢の同条件の公式分布がないため）。
- 実行順は **(1)父母の年齢を同時抽選 → (2)母親年齢から既婚/未婚を判定**。未婚家庭も内部ではモデル上の父親年齢を保持するが、婚外出生の父親年齢の実測根拠がないため画面上は従来どおり「不明」と表示する。値は統計的に確認された実父年齢を意味しない。
- 以前の母親単独抽選用 `mother_age_probabilities_2025.js` と婚内父年齢条件付き抽選用 `father_age_probabilities_2025.js` は履歴比較用に残すが、ゲーム画面からは読み込まない。
