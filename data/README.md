# 出生地ガチャ｜2025年計算データ

- `birthplace_probabilities_2025.xlsx`：Excel計算用。都道府県別出生数、確率、累積確率、JavaScript用出力。
- `birth_prefecture_2025.csv`：計算済み数値をゲーム側へ渡すためのデータ。
- 分母は47都道府県の出生数 **671,255人**。全国確定出生数 **671,270人**との差15人は住所地が外国。
- 数値の出典：厚生労働省 人口動態統計（確定数）2025年 上巻4-3。現在のゲーム内47都道府県データを転記したため、**各県の原表との最終突合は未完了**。
- 統計対象は国内の日本人出生。外国籍住民の出生を含める場合は別途統計を拡充する。
- 今回は `index.html` を変更しない。ゲームへの反映は後で行う。
